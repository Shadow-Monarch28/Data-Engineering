# Salary Dashboard – Excel Analytics Project

## 📊 Project Overview
This project is an **interactive Salary Dashboard built using Microsoft Excel**, designed to analyze salary patterns across companies, countries, job roles, and application modes.

The dashboard provides a clear view of **who works where**, **in which company**, **in which country**, **how they applied**, and **how salary varies by job type and job title**.  
It demonstrates strong **intermediate-level Excel data analysis and dashboarding skills**.

---

## 🛠 Tools & Skills Used

### Microsoft Excel (Intermediate)
- Data Cleaning & Preparation
- Structured Tables
- Sorting & Filtering
- Conditional Formatting
- Pivot Tables
- Pivot Charts
- Slicers
- Calculated Fields
- Lookup logic (VLOOKUP / XLOOKUP concepts)
- Dashboard Layout & Design

---

## 📁 Dataset Description
The dataset is maintained in an Excel file and contains employee/job-level information including:

- Person Name
- Company Name
- Country
- Job Title
- Job Type (e.g., Full-time, Contract, Internship)
- Salary
- Application Mode (e.g., Online, Referral, Walk-in)
- Work Mode (Remote / Hybrid / Onsite)

🌍 **Country information is visualized using a world map**, enabling geographic comparison of salary distribution.

---

## 📊 Dashboard Features

### Key Views & Analysis
- **Salary distribution by job title**
- **Salary comparison by job type**
- **Company-wise and country-wise salary analysis**
- **Application mode analysis** (how candidates applied)
- **Person-to-company mapping** (which person works in which company)
- **Geographical salary view using a world map**
- Interactive filtering using **slicers**

---

## 🔍 What This Dashboard Answers
- Which **job titles** offer higher salaries?
- How salary varies by **job type**?
- Which **countries** and **companies** pay more?
- How **application mode** relates to roles and salary?
- Who is working in **which company and country**?

---

## 📈 Business Insights (Example)
- Certain job titles consistently command higher salaries across countries.
- Full-time roles show higher median salaries compared to contract roles.
- Salary levels vary significantly by country, clearly visible through the world map visualization.
- Application mode patterns differ by job type and company.
